# Release

## Initial Packaging Targets

- AppImage.
- `.deb`.
- Optional Flatpak later.

## Desktop Integration

Planned integration:

- `.desktop` launcher from Tauri bundle metadata.
- Tray icon.
- Autostart via `~/.config/autostart/twokey-ai.desktop`.
- Logs under `~/.local/state/twokey-ai/` or `~/.cache/twokey-ai/logs/`.

## Current Phase 10 Status

- AppImage bundle is generated by `npm run tauri:build`.
- `.deb` bundle is generated by `npm run tauri:build`.
- Autostart can be toggled from settings and writes/removes `~/.config/autostart/twokey-ai.desktop`.
- Uninstall for `.deb` should use the package manager once package metadata is finalized.
- AppImage uninstall is manual: remove the AppImage and optional XDG config/cache/data directories.

## Updates

Auto-update is planned, not implemented.

Initial strategy:

- Check GitHub Releases.
- Compare local version.
- Show update notice.
- Open download link.

Fully automatic updates should only be added when signing and rollback behavior are clear.
